# STM32 Learning Projects Portfolio

This repository tracks my progress in embedded systems development using the STM32.

## Project Directory

| Project | Description |
| :--- | :--- |
| **01-GPIO-Blink** | Fundamental GPIO output control to toggle an LED. |
| **02-traffic-light-controller** | Sequential state machine simulation for traffic light patterns. |
| **03-Button-Interrupt** | Implementing External Interrupts (EXTI) for event-driven input handling. |
| **04-usart_printf** | Establishing serial communication to stream data to a PC terminal. |
| **05-led-buzzer-notes** | Generating PWM signals for LED dimming and frequency-based audio. |
| **06-seven-segment-1to9** | Multiplexing GPIOs to drive a 7-segment display for counting. |
| **07-sensors-temp** | Analog data acquisition using ADC for temperature monitoring. |
| **08-light-sensor** | LDR-based ambient light detection with threshold-based LED logic. |

---

## Technical Overview
* **Hardware:** STM32F4 series development boards.
* **Toolchain:** STM32CubeIDE & STM32CubeMX.
* **Methodology:** Manual peripheral configuration vs. HAL abstraction.
